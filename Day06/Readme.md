# SQL Journey — Day 06

## Topic

## Goal

## Topics Covered

* Why JOINs are used
* Primary Key and Foreign Key
* INNER JOIN
* LEFT JOIN
* RIGHT JOIN
* FULL OUTER JOIN
* CROSS JOIN
* JOIN with WHERE
* JOIN with GROUP BY
* JOIN with HAVING
* Joining multiple tables

## Practice

Use the existing tables in the SQL Journey database wherever possible.
