# SQL Journey — Day 08

## Topic

Window Functions + Data Cleaning

## What You Will Learn

In Day 08, you will learn:

* Window Functions
* `OVER()`
* `PARTITION BY`
* `ROW_NUMBER()`
* `RANK()`
* `DENSE_RANK()`
* `LAG()`
* `LEAD()`
* Running totals
* Top N per group
* `NULL`
* `IS NULL`
* `IS NOT NULL`
* `COALESCE()`
* `NULLIF()`
* Finding duplicate data

## Main Goal

By the end of Day 08, you should understand how to perform calculations across rows without losing individual rows.

You should also be able to handle basic missing and duplicate data.

Before starting Day 08, you should understand:

## Important Interview Concepts

You should be able to explain:

* What is a Window Function?
* Difference between GROUP BY and Window Functions
* What does `OVER()` do?
* What does `PARTITION BY` do?
* Difference between `ROW_NUMBER()`, `RANK()` and `DENSE_RANK()`
* Difference between `LAG()` and `LEAD()`
* What is NULL?
* Difference between NULL and 0
* What does `COALESCE()` do?
* What does `NULLIF()` do?
